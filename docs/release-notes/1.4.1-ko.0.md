| 항목 | 내용 |
| --- | --- |
| 누가 | `YMO1215/crosspoint-reader-ko-ai` 유지보수자 |
| 언제 | upstream CrossPoint `1.4.1` 반영 시점 |
| 어디서 | GitHub 저장소 `YMO1215/crosspoint-reader-ko-ai`와 GitHub Releases |

| 어떻게 | upstream `1.4.1`을 병합하고, 한국어 포크의 `.epdfont`/시스템 글꼴/CJK 안정화 패치를 보존했다 |

## 기준

- upstream 기준: `crosspoint-reader` `1.4.1`
- 한국어 안정화 기준: `crosspoint-reader-ko` `1.3.0-ko.1` 이후 `release/korean`
- 배포 대상: `YMO1215/crosspoint-reader-ko-ai`

## 주요 변경

- upstream `1.4.1`의 상태바 시계 왼쪽/오른쪽 표시 선택을 반영했습니다.
- 웹 설정의 상태바 시계 왼쪽/오른쪽 라벨 순서를 firmware 저장값과 맞춰 보정했습니다.
- upstream `1.4.1`의 `fillRectDither`/렌더러 최적화와 파일 경로 정규화 최적화를 반영했습니다.
- 파일 관리자 breadcrumb 표시 개선과 Calibre 사용 안내 보강을 반영했습니다.
- 읽기 방향 설정의 `Portrait 180` 표시 키를 한국어 UI에 맞춰 추가했습니다.
- 한국어 포크의 `.epdfont` SD 글꼴 체계와 UI 시스템 글꼴 선택 기능을 유지했습니다.
- 시스템 글꼴의 glyph 단위 Pretendard fallback을 유지했습니다.
- 대형 CJK SD 글꼴 interval table on-demand 탐색과 XTC 메모리 안정화를 유지했습니다.
- OTA 조회 대상 저장소는 `YMO1215/crosspoint-reader-ko-ai`로 유지했습니다.
- GitHub Release는 태그 push 시 자동 생성되며, 이 release notes 파일을 본문으로 사용합니다.

## 유지한 한국어/CJK 정책

- `.cpfont` 대신 `.epdfont`를 사용합니다.
- 릴리스 빌드는 EN/KO 중심으로 유지해 firmware 크기 예산을 관리합니다.
- `characterWrap`, `paragraphIndent`, 한국어 line compression, justify gap 완화는 회귀 금지 항목입니다.
- `firmware.bin`은 locked X4 단일 OTA 설치를 위해 6.25 MB stock OTA partition 한도를 기준으로 확인합니다.

## 업데이트 방법

- OTA: Wi-Fi 연결 후 설정 -> 시스템 -> 업데이트
- SD: Release의 `CrossPoint-1.4.1-ko.0-firmware.bin` 또는 `firmware.bin`을 SD 카드에 복사 후 설정 -> 시스템 -> SD카드 펌웨어 업데이트
- 수동 플래시: Release의 bootloader/partitions/firmware 파일을 ESP32-C3 offset에 맞춰 기록
