## 기준

- upstream 기준: `crosspoint-reader` `1.4.0`
- 한국어 안정화 기준: `crosspoint-reader-ko` `1.3.0-ko.1` 이후 `release/korean`
- 배포 대상: `YMO1215/crosspoint-reader-ko-ai`

## 주요 변경

- upstream `1.4.0`의 EPUB, 북마크, RTL, 이미지 렌더링, KOReader Sync, 키보드/reader 개선을 반영했습니다.
- 한국어 포크의 `.epdfont` SD 글꼴 체계를 유지했습니다.
- 읽기 본문 글꼴과 UI 시스템 글꼴을 각각 SD `.epdfont`로 선택하는 기능을 유지했습니다.
- 시스템 글꼴의 glyph 단위 Pretendard fallback을 유지했습니다.
- 대형 CJK SD 글꼴 interval table on-demand 탐색을 유지했습니다.
- XTC 1-bit 페이지 밴드 스트리밍과 glyph cache 정리 안전망을 유지했습니다.
- OTA 조회 대상 저장소를 `YMO1215/crosspoint-reader-ko-ai`로 변경했습니다.
- GitHub Release는 태그 push 시 자동 생성되며, release notes 파일을 본문으로 사용합니다.

## 유지한 한국어/CJK 정책

- `.cpfont` 대신 `.epdfont`를 사용합니다.
- 릴리스 빌드는 EN/KO 중심으로 유지해 firmware 크기 예산을 관리합니다.
- `characterWrap`, `paragraphIndent`, 한국어 line compression, justify gap 완화는 회귀 금지 항목입니다.
- `firmware.bin`은 locked X4 단일 OTA 설치를 위해 6.25 MB stock OTA partition 한도를 기준으로 확인합니다.

## 업데이트 방법

- OTA: Wi-Fi 연결 후 설정 -> 시스템 -> 업데이트
- SD: Release의 firmware 파일을 SD 카드에 복사 후 설정 -> 시스템 -> SD카드 펌웨어 업데이트
- 수동 플래시: Release의 bootloader/partitions/firmware 파일을 ESP32-C3 offset에 맞춰 기록
