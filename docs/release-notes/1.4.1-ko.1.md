# 1.4.1-ko.1 Release Notes

## 6하 원칙

| 항목 | 내용 |
| --- | --- |
| 누가 | `YMO1215/crosspoint-reader-ko-ai` 유지보수자 |
| 언제 | `1.4.1-ko.0` 설치 후 한국어 본문 간격/배치 회귀를 확인한 시점 |
| 어디서 | GitHub 저장소 `YMO1215/crosspoint-reader-ko-ai`와 GitHub Releases |
| 무엇을 | CrossPoint `1.4.1` 기반 한국어 AI 빌드의 본문 레이아웃 보정 |

| 어떻게 | upstream 1.4.x CJK 사전 분할 로직을 한국어 character-wrap 경로에서는 건너뛰고, 한국어 포크의 기존 `layoutCharacterWrap()` 배치 방식을 우선했다 |

## 기준

- upstream 기준: `crosspoint-reader` `1.4.1`
- 한국어 보기 기준: `crosspoint-reader-ko` `release/korean`
- 배포 대상: `YMO1215/crosspoint-reader-ko-ai`

## 주요 변경

- EPUB 본문에서 `characterWrap + Justified`일 때 한국어 단어를 `addWord()` 단계에서 미리 문자 단위로 쪼개지 않도록 했습니다.
- 줄 채움, 띄어쓰기, 자간 조정은 한국어 포크의 기존 `layoutCharacterWrap()` 흐름에서 처리되도록 복원했습니다.
- 1.4.1-ko.0에서 생성된 EPUB section cache가 남아 예전 배치가 유지되지 않도록 section cache version을 올렸습니다.
- `.epdfont` SD 글꼴 체계, reader/system font 선택, Pretendard fallback 정책은 그대로 유지했습니다.

## 업데이트 방법

- OTA: Wi-Fi 연결 후 설정 -> 시스템 -> 업데이트
- SD: Release의 `CrossPoint-1.4.1-ko.1-firmware.bin` 또는 `firmware.bin`을 SD 카드에 복사 후 설정 -> 시스템 -> SD카드 펌웨어 업데이트
- 수동 플래시: Release의 bootloader/partitions/firmware 파일을 ESP32-C3 offset에 맞춰 기록
